# Inputs
- The ATM system is set with a default PIN of "1234" for user authentication.

- The initial balance should be set to RM1000.00.

- User Authentication: The program should prompt the user to enter a 4-digit PIN. If the entered PIN is incorrect (not "1234"), the program should display an error message and exit.

- ATM Operations: Once authenticated, the user should be presented with the following options:
1. View Balance
2. Deposit Money
3. Withdraw Money
4. Exit
